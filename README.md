## How to use code
Step 1:
    cd to your workspace
Step 2:
    colcon build --packages-select autonavtest
step 3:
    source install/setup.bash
step 4:
    ros2 launch autonavtest launch_sim.launch.py 
step 5: 
    In a new terminal run teleop
