Nav2 Autonomous Navigation Implementation Plan for Swerve Rover

Goal Description

Integrate the ROS 2 Navigation Stack (Nav2) with the swerve rover codebase (autonavtest).

The rover currently runs Gazebo Sim physics, swerve kinematics (swerve_controller.py), EKF odometry fusion (robot_localization), and 3D SLAM with 2D occupancy grid generation (rtabmap). This plan defines the complete architecture to bring up Nav2 for full waypoint navigation and obstacle avoidance using: 1. RTAB-Map SLAM costmap integration (/map -> global_costmap) 2. Real-time 2D/3D obstacle detection (/scan + /depth_camera/image_raw/points -> local_costmap) 3. Holonomic / Omnidirectional path tracking (DWB local planner configured for swerve v_x, v_y, ω_z commands) 4. Behavior Tree navigation orchestration (bt_navigator with recovery actions) 5. Interactive RViz2 Nav2 goal setting and costmap visualization

User Review Required

DESIGN DECISION: **Controller Choice (DWB Holonomic vs. MPPI):** We recommend starting with **DWB Local Planner** configured for **holonomic swerve motion** (`holonomic_robot: true`, allowing simultaneous v_x, v_y, and ω_z). DWB is lightweight, deterministic, and proven for swerve robots in simulation. Later, we can optionally test **MPPI** (`nav2_mppi_controller::MPPIController`) with `motion_model: "Omni"`.
SYSTEM ARCHITECTURE NOTE: **AMCL / map_server is NOT needed:** Because our rover uses **RTAB-Map SLAM** in real-time, RTAB-Map directly publishes the `/map` topic and the `map -> odom` TF transform. Nav2 will run in **SLAM navigation mode** (without `amcl` or `map_server`).

Proposed Changes

Grouped by component layer:

Component 1: Nav2 Configuration

[NEW] ros_ws/src/config/nav2_params.yaml

Central configuration file for all Nav2 nodes: - bt_navigator: Behavior tree executor with default navigate_to_pose_w_replanning_and_recovery.xml. - planner_server: - Plugin: nav2_navfn_planner::NavFnPlanner (Dijkstra / A algorithm). - Tolerance: 0.5m. - controller_server: - Plugin: dwb_core::DWBLocalPlanner. - Holonomic Configuration: holonomic_robot: true, min_vel_x: -0.4, max_vel_x: 0.6, min_vel_y: -0.4, max_vel_y: 0.4, max_vel_theta: 0.8. - Trajectory Critic Weights: BaseObstacle, PathAlign, GoalAlign, PathDist, GoalDist. - Goal Checker: xy_goal_tolerance: 0.25m, yaw_goal_tolerance: 0.25 rad. - Progress Checker: required_movement_radius: 0.2m, movement_time_allowance: 10.0s. - global_costmap: - Global frame: map, Robot frame: base_footprint. - track_unknown_space: true. - robot_footprint: "[[0.60, 0.45], [0.60, -0.45], [-0.60, -0.45], [-0.60, 0.45]]". - Layers: static_layer (listening to /map), obstacle_layer (marking /scan), inflation_layer (inflation_radius: 0.75m, cost_scaling_factor: 3.0). - local_costmap: - Global frame: odom, Robot frame: base_footprint. - rolling_window: true, width: 6.0m, height: 6.0m, resolution: 0.05m. - Layers: obstacle_layer (marking /scan), inflation_layer (inflation_radius: 0.75m, cost_scaling_factor: 3.0). - behavior_server: - Behaviors: spin (nav2_behaviors/Spin), backup (nav2_behaviors/BackUp), wait (nav2_behaviors/Wait). - velocity_smoother: - Enforces acceleration limits (1.0 m/s²) and prevents abrupt swerve motor jumps. - lifecycle_manager_navigation*: - Manages states for controller_server, planner_server, behavior_server, bt_navigator, velocity_smoother.
